# Senior-Design-Final-Project
# Overview

Our project is a gamified productivity Chrome extension designed to help students maintain focus, manage tasks, and reduce digital distractions. By integrating essential productivity tools with a rewarding digital pet system, this extension transforms mundane study sessions into engaging experiences.

The core innovation is the Avatar System: every time you complete a Pomodoro session or finish a task, your digital companion earns Brain Points. You can then feed, pet, and play with your avatar through mini-games, creating a positive feedback loop that encourages consistent focus habits.

# Installation 
- Clone or Download the repository
- Open Chrome and navigate to chrome://extensions/
- Enable Developer Mode (toggle in the top right)
- Click Load unpacked and select the extension's directory
- The extension should now be available in your Chrome toolbar
